## 0. 新 UX 层次（Pencil 图层 = 前端组件）

页面任务：先跑 Without，再跑 With，在同一张地图上看轨迹，在底栏对照 BeamID / 开销 / 吞吐 / 准确率。
画布：1920×1080，Shell 等比缩放，页面不滚动。

### 0.1 五层

| 层 | 本页 |
|---|---|
| 页面 | 开发期入口 `DT for Comm new`（高亮）；主操作是 ①② 的播放/重置 |
| 区域 | ShellHeader + Case3Page（MapStage 铺满 + MapHud 浮层 + BottomDock 钉底） |
| 组件 | 见 0.3 树。重复格子必须做成组件，禁止复制 20 份散图层 |
| 内容 | 点号 `P{n}`、BeamID、costPct、吞吐曲线、BA% 与次数；切图数字是代表态 |
| 装饰 | 导航弧底、地图场地、底栏圆角蒙版、梯形/横条光效。装饰必须挂在所属组件下 |

### 0.2 大布局

```text
Stage 1920×1080
├── ShellHeader     固定顶栏（全站共用，高度以新切图为准；现网旧值 78px）
└── Case3Page       顶栏以下全部；纵向：地图铺满，底栏 hug 钉在底部
    ├── MapStage    fill 剩余高度；overflow hidden
    └── BottomDock  钉底、宽度拉满；内部纵向：回溯表 + KPI 三列
```

- 主轴：上地图舞台 / 下钉底栏。**不再左右双地图。**
- 地图是唯一会缩放/旋转/平移的层；Hud 与底栏 **不随地图变换**（与旧皮「浮层不跟地图」同一条）。
- 底栏变高时，地图高度被挤短，不出现页面滚动。
- 窗口变化只走 Shell 缩放，业务页不重排。

        │   │   ├── SideControls         # ① without DT, 状态, 播放, 重置

**不要拆开的三件事：** 切图里的点位进度、①② 按钮、回溯格子属于 **同一张表** `PointBeamReplay`。列头是 P1…，行头是 Without/With 控制，单元格是 BeamID。Pencil 用 Auto Layout 表，不要先画一条独立进度条再拼格子。列头不可点回看；波束矩阵只跟当前点走。

### 0.4 小布局（组件内部）

| 组件 | 内部结构 | 溢出 / 空态 |
|---|---|---|
| BeamMatrixCard | Header → TitleRow → Grid → Legend | 无当前点：空网格；BeamID 用 `--` |
| PointBeamReplay | 标题 + 列头 + 两行（行头 hug，格子 fill） | N>20 只显示最近 20 列，可横向滑到最新；未跑的格 `--` |
| SideControls | 序号+侧名 / 状态文案 / 播放 / 重置 | 禁用态用切图「启动禁止」「重置禁止」；运行中播放键用执行中图标，不发 pause |
| ReplayCell | 标签（最优波\|预测波）+ BeamID | **禁止 X/Y**。有 DT 且可对比时对绿错红 |
| CostCompareCard | 标题；左 without 梯形+%；中轴 0–100%；右 with 梯形+%；角上开销变化 | 缺值 `--`；双方有效才算变化。**Gate 1.5**：fill 显隐跟 `data-state`，数字写死代表态，柱高固定 PNG。**正式端**：数字/显隐跟 `costPct`；变化公式见下；柱高默认不映射 `%`（见 00 D18） |
| ThroughputCompareCard | 标题+图例；绘图区 Gbps × 点位 | 缺点不补 0；N 动态 |
| BeamAccuracyCard | 大号 % +「预测准确率」；横条；正确/错误次数 | 无增量时只显示基线，次数可空 |

|---|---|---|

### 0.6 单地图：共享路线 + 开新轮清图（已与业务组对齐）

地图、预置路线、UE 车、实时点位 **只有一份，两侧共享**，不是左右各画一套。

| 时机 | 地图上画什么 |
|---|---|
| 初始 | 场地 + 预置路线/点标识（未跑样式）；无实时轨迹、无当前车（或车在起点未出发，Pencil 用未出发代表态） |
| Without 运行中 | 本轮实时轨迹 + UE 车跟当前点走；点标识随本轮进度点亮 |
| Without 完成 | **保留** 本轮跑完的轨迹/车/标识，不要立刻清掉 |
| 用户点 With 启动 | **先把地图恢复成初始**（轨迹、车、点标识全部回到未跑），再开始 With 这一轮 |
| With 运行中 / 完成 | 只显示 **这一轮** 的轨迹/车/点亮；不要把 Without 那轮的车辙叠在地图上 |

底栏回溯表 **不清**：Without 行的 BeamID 在 With 开跑后仍然保留，只是地图清。这不是改接口，是展示规则。

## 1. 一致（契约/状态机，不许改）

| 项 | 新 UX 证据 | 结论 |
|---|---|---|
| Without → With 顺序 | ① / ② 编号；无 DT 跑时 with 为「未开始」 | **保留** |
| 每侧独立 Start / Reset | 两行播放键 + 重置键 | **保留** |
| 单侧结果可保留 | 无 DT「已结束」时 with 仍可测 | **保留** |
| Cost 单位 `%` | 「开销对比」左右都是 `%`，无 dB | **保留** |
| 开销变化公式 | 样例 50%→25% 标「开销减少 50%」= `(with-without)/without` | **保留**；文案「减少/增加」随符号 |
| 吞吐按点位 | 横轴点位、纵轴 Gbps、双系列 | **保留** |
| BA = 百分比 + 对/错次数 | 「预测准确率」+ 正确/错误次数 | **保留**；公式仍是同 `no` 比 `selectedBeamId` |
| 现场环境 | 右上「现场环境 >」 | **保留**，仍走 Shell 弹窗 |
| 点位动态 N | 切图画了 20 格 | **保留窗口语义**：20 是可见窗口，不是总上限 |
| Reflection/LOS | 两张整页都没有紫弧 | **维持不渲染**；字段仍参与 With 完整点校验 |

REST、控制文件、完成门槛、失败重试、进页握手、截图规则：切图未推翻，**全部保留**。

点位波束回溯的显示规则（已与业务组对齐）：

- 无 DT 行：该点 `selectedBeamId`，文案按「最优波」+ ID，例如 `122`。
- 有 DT 行：该点 `selectedBeamId`，文案按「预测波」+ ID。
- 对/错：同一 `no` 的两个 ID 是否相等。
- 切图里的 `x(12) y(12)` **作废**，实现不得写 X/Y，不得把 BeamID 换算成坐标再展示。
- 左上「波束矩阵」仍是 16×16 画网格，那是把同一个 BeamID 落到格子里，不是新的 X/Y 业务字段。
- 有 DT 时：同一 `no` 上无 DT 最优波 + 有 DT 预测波叠一张网格；**不画扫描点**。轴统一 **0–15**（切图有 DT 面板曾写 1–16，不跟）。
- 列头只表示窗口/当前列，**不可点回看**；矩阵只跟当前点。

## 6. 已拍板（2026-08-19 对齐）

1. **暂停**：运行中只显示执行中图标，不发后端 pause/cancel。
2. **2D/3D**：2D 选中，3D 可见但禁用（灰），不隐藏；本期只接 2D。
3. **导航**：全站新顶栏；开发期五个 Tab，新增并高亮 `DT for Comm new`。三杠装饰不可点。
4. **P1–P20**：窗口样例；动态 N，可见最近 20。地图编号 Pencil 用 20 点代表态。
5. **回溯格子**：只显示 BeamID；列头不可点回看；波束矩阵只跟当前点。
6. **有 DT 波束矩阵**：同一 `no` 叠无 DT 最优波 + 有 DT 预测波；无扫描点；轴 0–15。
7. **单地图**：路线/UE/实时点位共享一份。一侧跑完后点下一侧 Start，地图先恢复初始再跑新轮；底栏历史不清。
8. **无 DT 跑时 with 播放键**：Pencil 用「启动禁止」，与现网互斥一致。
9. **本轮 Pencil 五态**：初始、无 DT 运行、无 DT 完成、有 DT 运行、有 DT 完成。重置/失败后续再画。
10. **2D 底图**：`场地2D.png` 等轴测图 + 轨迹叠加，不是俯视平面图。
11. **CostCompareCard 绑定（2026-08-24）**：Gate 1.5 保持 `data-state` 控 fill + 写死演示数（S0）；正式 React 按 `costPct` 绑数字/显隐/开销变化，梯形柱高默认固定代表态切图、是否跟 `%` 映射另开决策（S1 / 00 D18）。
