## 页面与状态清单

| 状态 | UX 证据 | 必须设计的可见行为 | 当前缺口 |
|---|---|---|---|
| `initial` | 无整页图 | Initial 三项就绪；Calibrated 与对比区为空态/等待态 | 缺失，需 Pencil 补建 |
| `calibrating` | 无整页图 | 保留 Initial；显示校准中；禁用重复启动；不沿用旧结果 | 缺失，需 Pencil 补建 |
| `execute-success-waiting` | 无整页图 | 命令已执行但仍等待完整结果；不能显示完成 | 缺失，可作为校准中子态或独立 frame |
| `completed` | 三张 UX 图 | Initial/Calibrated 六张热力图；右侧三组 CDF/均值；完成标识 | 已有参考，需结构化重建 |
| `failed` | 无整页图 | Initial 可见、Calibrated 清空、失败反馈与可重试动作 | 缺失，需 Pencil 补建 |
| `resetting` | 无整页图 | 清除反馈，随后回 `initial` | 可用过渡说明，不必独立最终 frame |

## 页面结构

| 区域 | 组件/内容 | 数据与状态边界 |
|---|---|---|
| Header | 品牌、标题、四个 Tab、选中态 | Shell 共享；case2 只控制自身 Tab 激活视觉 |
| 左侧测试对比 | Initial DT 列、Calibrated DT 列、启动/清除、三行热力图对 | 三项结果 case-local；固定地图与动态热力层分离 |
| 右侧 KPI 对比 | RSS/有效路径数/首径时延的 CDF 与均值柱图 | CDF、均值和降幅由当前 KPI 样本派生 |
| 反馈层 | 完成、校准中、失败、截图保存反馈 | 不改变数据结论；当前 UX 缺失三种状态视觉 |

## 可见数字与契约核对

| UI 区块 | 当前 UX 数字 | 参考数据/算法事实 | Gate 1 处理 |
|---|---|---|---|
| RSS 平均误差 | 5.0 -> 3.0，标 `↓50%` | 样本均值为 5.0 / 3.0，实际下降 40.0% | 数字与降幅绑定运行时计算；不冻结 50% |
| 有效路径数平均误差 | 4.5 -> 2.5，标 `↓50%` | 样本均值为 4.5 / 2.5，实际下降约 44.4% | 同上 |
| 首径时延平均误差 | 5.0 -> 3.0，标 `↓50%` | 当前样本均值为 3.95 / 1.95，约下降 50.6% | 用契约值动态展示，不能沿用截图占位数 |
| CDF | 两条对比阶梯线 | Calibrated 曲线左移才表示误差改善 | Pencil 只规定样式/布局；前端动态计算 |
