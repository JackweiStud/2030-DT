## 相对 UX PNG 的纠正

1. **完成态**：开始禁用、重置可用；状态写「已完成」。不用 UX 完成图里的暂停键和「测试中」。
2. **CEP**：两卡分别标 **CEP50%** 与 **CEP90%**。2026-09-15 用户追加要求：显示 DT 相对传统基站的变化百分比，预期降低、按实际数值计算。最新阶段决定：百分比后置，首版保持不画，不要求 Cursor 补入本次冻结设计。
3. **CDF 坐标**：代表态横轴为米（0–10 m 量级），不用 UX 的 0.003–0.015 厘米感刻度。
4. **吞吐横轴**：`1、2、3…样点`，不是时钟，不绑地图 Pi。
5. **空态**：CDF / CEP / NLOS / 吞吐用「--」或「等待最终统计」。不用 0 柱、0% 冒充已测。
6. **NLOS 完成示意**：按参考样本约 90% 量级，不用 UX 的 60。占比高不表示更好。
7. **点位窗口**：设计画 20 槽；脚注写明示意 N=38，窗口不是上限。实现跟 case3：最新 20 点。
8. **三方案**：始终同时显示，图例不可点隐藏。
9. **3D**：按钮可见、禁用。首版无反射路径。
10. **现场环境**：机制和弹窗与当前 case3 一致。
