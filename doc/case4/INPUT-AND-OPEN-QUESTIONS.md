## 参考样本核对（2026-09-13）

以下为仓库参考输入的计算结果，不是真实测试结论，也不批准修改参考文件。

| 方案 | 汇总 CEP50 / CEP90（米） | 假设 base 为逐行真值时的 XY 平均距离（米） | 吞吐率样本均值（Gbps） |
|---|---|---|---|
| 商用 gaode | 3.340 / 8.051 | 0.088 | 无对应文件 |
| 传统基站 without_dt | 1.364 / 3.545 | 0.136 | 9.005 |
| DT 辅助 with_dt | 0.146 / 0.465 | 0.090 | 8.426 |

计算依据：CEP 直接取 error_and_nlos 文件前 3 行并按 Excel 语义映射；XY 距离为逐行 sqrt((x-baseX)^2+(y-baseY)^2) 后取均值；吞吐取各文件算术均值。有 DT 吞吐均值相对无 DT 约低 6.4%。

汇总统计支持 DT 定位精度优势，但当前 XY 轨迹误差未体现相同优势与尺度。不能认定轨迹、CDF、CEP 是同一轮同一口径的自洽数据；是否同源、是否采用不同统计窗口仍需澄清。用户认可定位精度为核心、同时展示吞吐及 NLOS 的主线；没有授权据此加工真实数据或替换参考样本。
