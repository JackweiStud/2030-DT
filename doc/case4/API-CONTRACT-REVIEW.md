## 工程选择（已采纳，待冻结）

- `/trajectory`、按 side 分开的 `/throughput` 与聚合 `/result`，而非复制 case3 `/side`。
- 共享子目录为 `case4/`，明确清理九个动态文件。
- CDF/CEP/NLOS 保留输入精度；CDF 不要求最后概率恰好 1。坐标/吞吐进 JSON 为 2 位；`errorM`/`probability`/`p50M`/`p90M`/`nlosRatio` 不量化。CDF 与汇总同一文件内空白或逗号二选一。
- 实际轨迹超过 base 长度时无 Pi 参照，返回数据错误；不静默截断。
- 沿用可解析无换行末行策略，同时要求后端整行 append。
