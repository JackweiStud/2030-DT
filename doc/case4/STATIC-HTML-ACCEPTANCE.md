## 已知偏差

1. 底栏按 Pencil `#ffffff66`、无 blur；与 case3 深色底栏不同，属定稿差异。
2. 地图优先使用 Pencil 固定 20 点及三条代表态轨迹，不随数据集实际坐标/点数变化；误差与统计使用示意数据，均非本轮真实采集。
3. `adapter-error` 无独立 Pencil 帧，为同构 + 横幅派生；等待统计/开始失败/重置失败/结果不完整已按用户确认移出静态验收。
4. 本目录只服务 Gate 1.5 静态验收。正式 Web 已于此后接入 case4 运行页（除 3D）；不得把本静态页当作运行路径。

## 三个目的与正式开发交接

| 目的 | 本阶段结论 |
|---|---|
| 验证视觉、高保真还原 Pencil | 用户已接受当前整体效果，保留作为正式开发视觉依据 |
| 验证结构能承载数据变化 | 结构准备基本具备：地图分层、独立 DOM/SVG、误差窗口与不等长吞吐；动态正确性尚未完整验证 |
| 为 React 留下可用成果 | 已有可复用的图片、样式与组件结构；示意数据、假交互和固定几何不进入正式运行路径 |

以下问题已识别，按用户确认留到正式 React 开发处理，不作为本次静态验收阻塞：

| 正式开发项 | 当前限制 | 最小验收 |
|---|---|---|
| 地图数据驱动 | `renderMap` 优先固定 Pencil 图形；修改实际坐标不改变轨迹 | 使用同一投影驱动预期路线、三方案轨迹、点位与 UE；修改坐标能更新对应点；覆盖超过 20 点、38 预期／30 完成，不补造剩余点 |
| CDF 数值映射 | 横轴固定 0–4.5，超出范围的 X 被压到右边界 | 直接消费后端 CDF 文件；三曲线使用共同轴域，或明确观察窗口并裁剪，不能压缩越界值改变分布 |
| CEP 数值映射 | 特定 CEP50 示例值触发固定柱高，CEP90 数字变化时柱高可能不变 | 按后端 CEP 数据及共同数值比例绘柱，数字与柱高同步变化；不迁移示意特例 |
| 误差轴与曲线比例 | 固定标签等距排布，与线性点位比例并非完全一致 | 刻度与曲线共用同一数值映射，并处理数据范围变化 |
| 正式交互与截图 | 静态仅切换代表态，不验证控制流程；SVG 截图尚未验收 | 按 case4 契约实现忙态锁、刷新/撤权、失败恢复、最终结果收齐和截图收尾；检查实际 PNG 内容 |

首版仍不实现 CEP 增减百分比、单点悬停、3D 或反射。静态绘图的问题不能以“视觉已接受”为由视为正式功能通过，也无需在静态页面重复建设正式业务逻辑。
