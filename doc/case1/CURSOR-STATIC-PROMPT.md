## 实现范围

### 固定舞台与结构

- 舞台 1920×1080，按 `min(viewportWidth/1920, viewportHeight/1080)` 整体缩放居中；无第二套断点重排、无页面滚动条。
- 顶栏做独立 Shell 参考区域；case1 业务放 `.case1-page` 下，CSS 作用域隔离。只在静态目录复现，不改正式 Shell。
- 左导航稳定，右侧局部换内容；首页/详情精确尺寸差异以实际设计为准，不擅自统一。区域使用语义容器及 flex，菱形堆叠、图表绘图区和浮层可局部定位；不能整页每个元素都绝对定位。
- 必须用独立文字/图形还原 KPI、标签和图例，不能用四张整帧截图切换冒充 HTML，也不能把整个 KPI 截成一张图片。
- 可通过 Pencil 导出作为起点，但须检查生成结构、相对资源路径和字体，整理成可迁移样式/组件分区，完成浏览器对照，不能把一次 Export 当作完成。

### 点击规则

- 初始 home：五张菱形图片全部正常显示。
- 只有几何、电磁材质、RF 三张图片可点击。点击进入对应详情，当前图片原色，另外四张图片按设计变暗；变暗的另两张可点击入口仍能切换。
- 在详情再次点击当前层图片回首页，恢复五图正常显示。
- 知识图谱、数字孪生应用层没有点击动作，不要添加占位弹窗或“建设中”提示。
- 三个入口用可键盘操作的按钮/等价语义，支持 Enter/Space；禁用层不进入 Tab 焦点。
- 顶栏其他 case 只作静态展示，不加载或复制其业务页面；不要连到正式运行页。

### 素材与数据边界

- 按当前设计引用的素材复制必要文件到静态 `assets/`，保留清晰来源。不要整包复制未引用备用素材，不修改原图。
- 几何/电磁主视图区使用 Pencil 的代表图，精确复现裁切、圆角与层级；不加载 GLB、不加鼠标 3D 交互、不做模型预加载、不加旋转提示或额外工具。
- RF 用 Pencil 的当前地图和色标，保留用户已接受的画面；纯底图仍待替换，本阶段不读取 TXT 或实现热力数据融合。
- 不访问 `/api`、共享目录、WebSocket，不引入轮询、后端进程或配置写入。JS 仅处理本地页面选择、舞台缩放与必要假交互；不用 localStorage 保存选择。
- 所有示意数据集中在静态页面数据结构中，给未来迁移留边界；不新增实时业务状态机。
- 默认画面不增加开发说明、测试面板或错误横幅。必要的代表性内容变化检查可在本地测试脚本/临时 DOM 注入中进行，不改变默认展示，不预建全部异常页。
- 地图/模型代表图的裁切、位置与组偏移只服务静态对照，不冒充正式业务坐标投影或相机参数；未来需独立标定。禁止为贴合静态截图提前实现任意坐标映射。
- 空态先查设计源实例的显隐和文案，不能默认所有无数据都改成 `--`。当前四帧未定义的缺值仅做临时结构检查并记录，不擅自增加第五个用户页面。
- 若后续发现确需派生局部提示，先在验收文档说明挂载点及阶段归属，再核对父级 overflow，不能加完后任其被裁切；本轮不主动扩展 Pencil 没有的横幅/弹层。
- 三轨分离：`03-design/case1/` 是设计源，`web-static/case1/` 是静态验收产物，正式 `code/web` 资源在后续另行迁移。静态调试开关、URL 状态模拟、假数据和假业务行为不得迁入正式运行代码；本地导航/样式仅按职责重新接入正式实现。

4. 在至少一个较小窗口（例如 1440×900）验证整体等比缩放、居中、无滚动条，点击区域仍正确。
5. 浏览器验证三入口所有切换/再次点击回首页、两层非交互、键盘操作和刷新回首页；无资源 404、无控制台异常、无业务网络请求。
