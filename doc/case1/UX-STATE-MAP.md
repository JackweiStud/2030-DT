# case1 UX 状态映射

需求依据：[PHASE0-SCOPE.md](PHASE0-SCOPE.md)。当前以用户已通过的 Pencil 四主帧为静态视觉标准。用户已授权需求充分清楚后进入下一 Gate；常规设计细节按下文默认推进，不增加业务功能。

## 四个主页面

| Frame | 右侧内容 | 左侧五张图片 | 数据与操作 |
|---|---|---|---|
| home | 五层架构说明、配图与标签 | 全部正常显示 | 几何/电磁材质/RF 可点；知识图谱/应用层不可点；后台顺序准备两个模型 |
| geometry | 描述、几何保真度、重构覆盖率、3D 几何模型 | 几何原色，其余暗 | 当前图再点返回 home；可切其他可点层；模型旋转/缩放/平移 |
| material | 描述、电磁信道保真度、材质图例、3D 材质模型 | 电磁原色，其余暗 | 同上；材质图例默认只展示，不筛选、不改材质 |
| rf | 描述、RSS 误差对比、二维 RSS 热力图及一致色标 | RF 原色，其余暗 | 当前图再点返回 home；可切其他可点层；不扩展为第三个 3D 场景 |

暗态不代表全部禁用：几何/电磁/RF 始终保留点击能力；另两层始终非交互。不另弹新窗口、不改共享 Shell、不引入 Start/ReInit。支持键盘聚焦与 Enter/Space 操作三个入口，选中态与可点击态分开表达。

## 局部资源态（组件变体，不扩展业务页面）

| 变体 | 表达位置 | 交互规则 |
|---|---|---|
| 模型准备中 | 当前模型视图区 | 加载提示，不伪造百分比；左侧仍可切换 |
| 模型加载失败 | 当前模型视图区 | 明确失败和局部重试；不使用截图冒充可交互模型 |
| 数据读取中/失败 | 对应 KPI 或 RF 区域 | 未有值显示占位，失败显示简短原因/重试；不显示 UX 固定值 |

首页不因预加载失败而整体报错。首次进入详情按页读取离线 TXT，停留 case1 期间缓存；切离后重新进入再按需读取。该缓存规则为本轮工程默认，非实时订阅。视角只保留在本次 case1 内存中；切离 case 或刷新/重开后恢复配置初始值，不持久化。调试开关默认关闭，开启可查看并复制视角参数供用户手工配置。

## 正式数据绑定参考（不替换已接受的静态 Pencil 示意）

下表来自现有 TXT，供后续数据绑定核对。用户明确 Gate 1.5 保留当前 Pencil 的 0.2/0.4/50% 示意，不以本表改动静态视觉；正式图表不得硬编码设计示意值。

| 指标 | RF off | RF on | 相对变化（1 位小数） |
|---|---:|---:|---|
| 几何保真度 | 0.85 | 0.90 | 上升 5.9% |
| 重构覆盖率 | 0.82 | 0.91 | 上升 11.0% |
| 电磁信道保真度 | 0.88 | 0.92 | 上升 4.5% |
| RSS 误差 | 1.2 | 0.8 | 下降 33.3% |

设计默认：变化率 `(on-off)/off×100%`，箭头按实际增减；前三项升为改善，误差降为改善，不能强制所有输入改善。off=0 时隐藏百分比，不除零；相等时隐藏变化徽标。柱形保留真实量级，保真度/覆盖率轴域 0～1；RSS 误差纵轴按数据上界留白，不照抄 UX 0～1 导致 1.2 越界。标签精度暂按 2 位小数、百分比 1 位小数，设计冻结时核对。

## 与 UX 的明确差异

- 顶部采用当前运行 Shell 的标题和导航，UX 旧顶栏不覆盖项目 Shell。
- UX 左侧 Layer 3 重复写为“电磁层”，按已确认业务改为“RF 层”。
- 静态数字以当前 Pencil 为准；TXT 样例与实际变化方向留给正式数据绑定验收。
- RF 色标按 case2 渲染机制匹配蓝→青→黄→红，原色标图片仅作布局参考。
- 不新增 Reset/保存反馈；此前持久化与复位方案已由用户撤销。
- 当前 RF 图片内嵌网格，仅作设计布局示意；无网格底图由用户替换，后续单独验收数据叠加与坐标。

## 冻结检查

四主帧尺寸均为 1920×1080；逐项核对左右区域位置、五图明暗、三个入口、KPI 内容与数据层、材质非交互图例、正常画面无额外控件。必须有可编辑设计源、结构检查和实际截图对照，用户已确认视觉及结构 PASS；附加调试功能不默认显示。3D 相机最终值和纯底图标定在正式运行环境验证，设计图片不能证明已完成。
