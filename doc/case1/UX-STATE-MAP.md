需求依据：[PHASE0-SCOPE.md](PHASE0-SCOPE.md)。本文件是 Gate 1 设计输入，不是已冻结设计。用户已授权需求充分清楚后进入下一 Gate；常规设计细节按下文默认推进，不增加业务功能。

|---|---|---|---|

## 局部资源态（组件变体，不扩展业务页面）

| 变体 | 表达位置 | 交互规则 |
|---|---|---|
| 模型准备中 | 当前模型视图区 | 加载提示，不伪造百分比；左侧仍可切换 |
| 模型加载失败 | 当前模型视图区 | 明确失败和局部重试；不使用截图冒充可交互模型 |
| 数据读取中/失败 | 对应 KPI 或 RF 区域 | 未有值显示占位，失败显示简短原因/重试；不显示 UX 固定值 |
| 视角保存中/已保存/失败 | 3D 工具区旁短反馈 | 失败允许重试；反馈不能遮挡模型或撑开版式 |
| Reset | 当前模型工具区 | 仅恢复当前层初始视角并持久保存，不影响另一层 |

首页不因预加载失败而整体报错。首次进入详情按页读取离线 TXT，停留 case1 期间缓存；切离后重新进入再按需读取。该缓存规则为本轮工程默认，非实时订阅。保存视角跨 case/重开 Web 保留，释放渲染资源不删除保存值。

## KPI 设计样例与默认规则

样例来自现有 TXT；数值仅用于设计绑定核对，不硬编码到正式图表。

| 指标 | RF off | RF on | 相对变化（1 位小数） |
|---|---:|---:|---|
| 几何保真度 | 0.85 | 0.90 | 上升 5.9% |
| 重构覆盖率 | 0.82 | 0.91 | 上升 11.0% |
| 电磁信道保真度 | 0.88 | 0.92 | 上升 4.5% |
| RSS 误差 | 1.2 | 0.8 | 下降 33.3% |

设计默认：变化率 `(on-off)/off×100%`，箭头按实际增减；前三项升为改善，误差降为改善，不能强制所有输入改善。off=0 时隐藏百分比，不除零；相等时隐藏变化徽标。柱形保留真实量级，保真度/覆盖率轴域 0～1；RSS 误差纵轴按数据上界留白，不照抄 UX 0～1 导致 1.2 越界。标签精度暂按 2 位小数、百分比 1 位小数，设计冻结时核对。

## 与 UX 的明确差异

- 顶部采用当前运行 Shell 的标题和导航，UX 旧顶栏不覆盖项目 Shell。
- UX 左侧 Layer 3 重复写为“电磁层”，按已确认业务改为“RF 层”。
- 原 UX 示意 0.2/0.3、上升 50% 换为样例对应数值与实际变化方向。
- RF 色标按 case2 渲染机制匹配蓝→青→黄→红，原色标图片仅作布局参考。
- 新增模型 Reset 与保存反馈，放在模型工具区域；不新增业务重置。
- 当前 RF 图片内嵌网格，仅作设计布局示意；无网格底图由用户替换，后续单独验收数据叠加与坐标。

## 冻结检查

四主帧尺寸均为 1920×1080；逐项核对左右区域位置、五图明暗、三个入口、KPI 内容与数据层、材质非交互图例、工具区及局部错误/保存反馈。必须有可编辑设计源、结构检查和实际截图对照，用户确认后才能标记冻结。3D 相机最终值和纯底图标定在正式运行环境验证，设计图片不能证明已完成。
