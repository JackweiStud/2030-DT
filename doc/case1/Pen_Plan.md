## 帧与组件树

四主帧：`case1-home`、`case1-geometry`、`case1-material`、`case1-rf`，各 1920×1080。另设组件状态样板区承载资源 loading/error、save pending/success/error、Reset，不为组合状态复制大量整页。

```text
case1-主帧
├─ 共享Shell参考（现有顶栏，不修改其所有权）
└─ case1-内容区（横向）
   ├─ 左侧分层导航（固定宽）
   │  ├─ 分层标题
   │  └─ 五层导航组（图片、标签、所属连接线）
   └─ 右侧内容（fill）
      ├─ 区域标题
      └─ 首页说明组 或 详情组
         ├─ 概述行（描述标签 + KPI卡/材质图例）
         └─ 主视图区（3D代表图 或 RF底图/热力/色标）
            ├─ 工具区（3D交互提示、Reset）
            └─ 局部状态反馈
```

复用组件：五层导航（home/geometry/material/rf 四变体）、描述标签组、KPI 对比卡、静态材质图例、视图区、模型工具区、局部反馈。所有图层中文语义命名；数值、标签、单位、柱形与徽标独立可编辑。

## 布局合同

| 区域 | 父级/布局 | 尺寸与溢出 |
|---|---|---|
| 舞台 | Shell，固定 1920×1080 | 外部统一等比缩放，不新增断点重排 |
| 内容区 | Shell 下，横向 flex | 页面内固定可用高度；左右 gap 与外 padding 从 UX 测量 |
| 左导航 | 内容区，纵向；五图局部 stack | 固定宽；五图位置跨帧一致；暗态不影响尺寸/点击区 |
| 右区域 | 内容区，纵向 flex | fill；标题 hug；内容 fill；不出现页面滚动条 |
| 详情概述 | 右区域，横向 flex | 描述/KPI 分组，内部 gap/padding 统一 |
| KPI 卡 | 概述行，纵向 flex | 标题/数值标签 hug，绘图区 fill；RSS 轴域适配样例 |
| 主视图区 | 详情组，fill | 图像/渲染裁切到圆角；工具/反馈位于独立上层容器，避免被错误裁切 |

token 草案只命名不虚构精确值：页面背景、卡片背景、主要/次要文字、几何蓝、电磁紫、RF绿、选中图片正常亮度、未选图片暗度、面板圆角、区域间距、卡片内边距。先量四张 UX，再在设计工具中统一值；不把 RF 绿强调色等同于热力色标。

## 资产与动态层顺序

沿用分析文档资产表。图片原件不修改，设计需复制资源时放目标 `.pen` 同级 `assets/` 并登记来源；正式运行资源后续独立迁入 case1 资源目录。图表/数字用可编辑形状；RF 为底图 < 热力网格 < 色标；模型为代表图 < 操作工具 < 保存/错误反馈。资源态覆盖仅限所属面板。

RF 当前代表图保留“纯底图待替换”设计注释，不伪造已完成数值融合。3D 代表图保留“运行时 GLB”注释；不在 Pencil 绘制真实 3D 算法或运行状态机。
