## 代表态（不是状态机穷举）

当前 `.pen` **五帧流程态 + 一帧交互弹层**。`case3V1.有DT运行中` / `case3V1.有DT运行完成` 的帧名只表流程；画面对错是**代表态**（运行中=预测正确，完成=预测错误），不表示还要补「运行中错误 / 完成正确」两帧。对错差异看波束卡主组件（`波束矩阵卡-有DT-预测正确` / `波束矩阵卡-有DT-预测错误`）、标题行 `预测徽章-正确` / `预测徽章-错误`，以及 `对勾角标层`，不要从帧名拆状态机。

## 结构抽查

- 20 个回溯格、20 个列头、20 个路线点是组件实例，不是散图层。
- 16×16 由循环生成，不是 256 个手摆椭圆。
- 现场环境：独立帧 `case3V1.点击现场环境`；`现场环境浮层`（Overlay）内 `整页蒙版` + `现场环境弹窗`（`弹窗标题行` / `视频双列` / `视频列-基站视角` / `视频列-集装箱视角`）。
- 五流程帧 `回放格子对` 第三子级为 `对勾角标层`（absolute Overlay）。有 DT 两帧角标收在层内（完成 20 个、运行中 4 个）；其余三帧是空槽，结构对齐。
- 波束卡组件/实例统一：`波束矩阵卡-无DT` / `波束矩阵卡-有DT-预测正确` / `波束矩阵卡-有DT-预测错误`；有 DT 卡顶栏徽章为 `预测徽章-正确` / `预测徽章-错误`。
- 流程帧 `吞吐率对比卡` 均为组件 `fYdoo` 实例（有 DT 运行中保留短曲线 + 点 5–20 隐藏的代表态覆盖）。
- 地图舞台子层顺序一致：`场地底图 → 预置路线层 → 路线点位组 → 已走路线层 → 终端标记`。
- 播放/重置按钮按态命名：`播放按钮-{可启动|忙态|启动禁止}`、`重置按钮-{可用|禁用}`。

补充确认：初始态右下 BA 卡 `75.0% / 正确75 / 错误25` 是基线占位，不是后端结果。
