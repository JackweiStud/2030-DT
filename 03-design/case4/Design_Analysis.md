## 页面目标

在 1920×1080 内部演示舞台上，用 **预期轨迹 + 三方案实时轨迹 + 逐点误差 + 最终 CDF/CEP + 吞吐率 + NLOS** 讲清：数字孪生辅助定位的精度对比，同时展示吞吐与 NLOS 场景统计。

| 方案 | 文件/语义键 | 图例角色 |
|---|---|---|
| 传统基站定位 | `without_dt` | 蓝系实线/点（`$c4-bs`） |
| 商用方案定位（高德） | `gaode` | 橙色实线/点（`$c4-gaode`） |
| 数字孪生辅助定位 | `with_dt` | 紫色实线/点（`$c4-dt`） |
| 预期/计划轨迹 | `base` | 绿色（`$c4-plan`）；参照，不是第四种定位方案 |

## 用户任务

1. 初始核对场地、预期轨迹与预置点位；确认统计区为空态。
2. 点一次「开始」，观察三方案收齐后共同推进的轨迹、当前点、逐点误差；吞吐独立更新。
3. 完成后查看三线 CDF、CEP50%/CEP90%、NLOS；悬停误差区 Pi 看该点三方案误差（运行时浮层，无独立定稿帧）。
4. 点「重置」回到初始。失败时只重试对应命令。

## 视觉优先级

1. 当前能否开始/重置，以及测试是否结束。
2. 地图上预期轨迹 vs 三方案实时轨迹。
3. 误差回溯区的当前点与三色误差点。
4. 完成后的 CDF/CEP 与吞吐/NLOS。
5. 导航、2D|3D（3D 灰禁）、现场环境等 chrome。

## 前端可实现性风险（仍有效）

| 风险 | 建议 |
|---|---|
| 点数 > 窗口 | 设计 20 槽；实现按 N + 滚动 |
| 等轴测投影 | 复用 case3 `mapProjectionV2` |
| 逐点误差 vs 后端 CDF | 两套图，禁止用回溯点重绘 CDF |
