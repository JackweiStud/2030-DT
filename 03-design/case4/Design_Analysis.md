## 现有 .pen 基线

打开目标文件时，画布已有完整 **case3V1** 五业务帧 + 现场环境 + 可复用组件（共享顶栏、视图切换、路线点位、吞吐率对比卡、波束/开销/BA 等）。这是复用基线，不是 case4 交付帧。

处理原则：

- **保留**全部现有 case3V1 帧与组件，不删除、不改组件内部以免污染基线。
- **不修改** `03-design/case3/`、`03-design/case3V1/`。
- case4 在空白区 **新增** 帧与 case4 专用组件；仅通过实例 `descendants` 覆盖顶栏当前 Tab。
- 复用：场地底图、坐标映射视觉、预置路线/点位推进、2D|3D 切换（3D 可见灰禁）、现场环境弹窗、播放/重置切图、吞吐卡壳、1920×1080 Shell。
- 不复用：双侧启动、波束矩阵/回溯 BeamID、开销对比、BA、吞吐与地图 Pi 绑定。

当前线上 `DT for Comm` 对应 Case3 V2（`code/web/src/cases/case3-v2/`）。Pencil 基线来自 V1 皮，地图与 HUD 结构已与 V2 同构（单地图 + 底栏）。case4 按该结构改造业务层。

## 页面目标

在 1920×1080 内部演示舞台上，用 **预期轨迹 + 三方案实时轨迹 + 逐点误差 + 最终 CDF/CEP + 吞吐率 + NLOS** 讲清：数字孪生辅助定位的精度对比，同时展示吞吐与 NLOS 场景统计。

三种定位方案始终同时显示：

| 方案 | 文件/语义键 | 图例角色 |
|---|---|---|
| 传统基站定位 | `without_dt` | 蓝色实线/点 |
| 商用方案定位（高德） | `gaode` | 橙色实线/点 |
| 数字孪生辅助定位 | `with_dt` | 紫色实线/点 |
| 预期/计划轨迹 | `base` | 绿色虚线；参照，不是第四种定位方案 |

## 用户任务

1. 初始核对场地、预期轨迹与预置点位；确认统计区为空态。
2. 点一次「开始」，观察三方案收齐后共同推进的轨迹、当前点、逐点误差；吞吐独立更新。
3. 完成后查看三线 CDF、CEP50%/CEP90%、NLOS；悬停误差区 Pi 看该点三方案误差。
4. 点「重置」回到初始。失败时只重试对应命令。

## 视觉优先级

1. 当前能否开始/重置，以及测试是否结束。
2. 地图上预期轨迹 vs 三方案实时轨迹（始终四条语义，初始实时为空）。
3. 误差回溯区的当前点与三色误差点。
4. 完成后的 CDF/CEP（精度故事）与吞吐/NLOS（并列，不包装成全面优于）。
5. 导航、2D|3D、现场环境等 chrome。

## 数据与文案

- 逐点误差：定位相对 base 的 XY 欧氏距离，单位 m；第 i 行 = Pi。
- CDF/CEP：只读后端统计，不由界面点列重算。
- 吞吐：只 with_dt / without_dt；横轴样点序号。
- NLOS：DT 场景单项平均径占比；高不表示更好。
- 空态文案：「--」「未开始」「等待最终统计」；完成：「已完成」。
- 所有数字均为 **设计示意**，实现必须绑运行时数据。
- 示意完成值可参考样本数量级（CEP 米级、NLOS 高占比、有 DT 吞吐略低），**不强制**每轮 DT 全面更优。

## 不确定项

| 问题 | 影响 | 建议确认方式 |
|---|---|---|
| 65535 无效坐标 | 地图/误差该点怎么画 | 用户找后端；设计不画专用态 |
| 单次启动 dt_type | 与设计无关 | 后端确认 |
| 完成时点数 < 预期 | 完成帧是否画满窗 | 不预设；完成代表态按「已展示窗口已满」理解 |
| 吞吐是否同序号收齐 | 运行中双线是否等长 | 设计用等长示意并标注未定 |
| 重置何时清结果 | 重置中底栏有无旧数据 | 设计标注未定，不发明 |
| 逐点显示精度 | 浮层小数位 | 示意 2 位；契约再定 |
| 切回 Tab 规则 | 不画 | 契约 |

需要用户拍板、且会改设计语义的项：无（规则已写在 case4 文档）。其余为后端遗留，不阻塞本轮可审阅设计。
