## Pencil layout 语义（实现必读）

| Pencil `layout` | 含义 | 前端 |
|---|---|---|
| 缺省 / 未写 | **横排 flex** | `display:flex; flex-direction:row` |
| `vertical` | 竖排 flex | `flex-direction:column` |
| `none` | absolute / 叠层宿主 | `position` 叠层；**禁止**再当 flex 行 |

层名含 `横排·flex` / `absolute` / `非文档流` 时，按名实现，**禁止把 Pencil 的 left/top 写进业务 CSS**（地图变换与 canvas 槽除外）。

## 底栏 / 误差窗交接

| 区域 | Pencil 合同 | 实现必须 |
|---|---|---|
| 定位误差回溯区 | 横排 flex：`回溯控制列` hug + `误差Y轴` + `回放列区` fill；gap≈2 | 同左 |
| 点位列表头 | `layout:none` 挂载：`列头行（横排·flex）` + `进度叠层（absolute…）` + `当前点光标浮层（absolute）` | 列头按索引；进度/光标 absolute，**不是**第三/第四 flex 列 |
| 误差点区 | `误差点列窗（横排·flex空槽）`：`列几何槽-P*（空·仅定宽）` ×20；并列 `误差点叠层（对齐列中心·非抄left）` | **槽只定列几何**；业务点在叠层 `点列（按P索引绑定·非抄left）` → `点-Pi` |
| 连线 | `连线（示意·非实现源）` | SVG/`stroke-dasharray`；禁止照抄示意小矩形段 |
| 指标卡行 | 横排 flex：定位误差 ≈975 / NLOS ≈272 / `吞吐卡占位（宽623·内嵌组件）`；gap≈12 | flex 三卡；吞吐 DOM 一层即可，不必复刻占位壳 |
| 侧标竖线 / 侧标-测试方案 | 名含「预留·默认隐藏」，四屏 `enabled=false` | 静态页可不做 |

## 动态图形契约

### 地图

- 坐标系：`code/web/src/cases/case3-v2/mapProjectionV2.ts`，底图 `site-2d.jpg`（或 case4 assets 同源）
- 层序：底图 < 预期走廊 < 已走高亮 < 三实测系列 < 点位 < UE
- 子层「含校准偏移」必须并入**同一变换矩阵**，勿拆成多套原点
- Pencil 折线仅为代表态

### 误差窗

- Y：米；示意轴勿写死，实现按本轮误差范围定
- 三色 token：`$c4-bs` / `$c4-gaode` / `$c4-dt`（以 Pencil 变量为准）

### CDF / CEP / NLOS / 吞吐

- CDF：X 误差(m)，Y 概率 0–1；后端点列，不由回溯点重算
- CEP：三方案 ×50/90，单位 m，无增减%
- NLOS：单项占比；脚注高不表示更好
- 吞吐：X=样点序号 1,2,3…

## 禁止实现

- 暂停/继续、单方案图例显隐、真开 3D
- 静态页渲染反射路径（正式 Web 的 2D Reflection 见 `doc/case4/REFLECTION-SPEC.md`）
- 用 UX 的 20 点 / NLOS 60 / CEP Δ% / CDF 厘米轴做硬编码
- 把 Pencil 示意数字写进运行代码
- 把底栏/浮层 absolute `x`/`y` 当布局契约照抄
- 把 `列几何槽` 当业务点容器，或把 `连线（示意·非实现源）` 当实现源
- 在 65535 / dt_type / 完成点数不足 / 吞吐收齐上自行定业务规则
