### Pencil 底栏 / HUD 交接（防照抄）

底栏已改为真 flex（以 `mEyG6` 为视觉基准，其它业务态已同步）。**实现禁止把 Pencil 的 left/top 写进 CSS**；按 flex 契约实现即可。

| 区域 | Pencil 现状（基准 `mEyG6`） | 实现必须 |
|---|---|---|
| 定位误差回溯区 | 横排 flex：控制 ~106 + Y 轴 ~50 + 回放列区 fill；`gap:2` | 同左：控制 hug + 轴 hug + 列区 fill |
| 点位窗口 | `点位列表头` 下：`列头行`（仅 `列头-P1…P20`）+ 运行态绝对浮层 `进度叠层（浮层·非列）` / `当前点光标浮层`；与 `槽-P1…P20` 按索引对齐 | 只遍历 `列头-P*` / `槽-P*`；**忽略**名含「浮层·非列」的叠层与光标；布局仍是「一列」按索引 `i` 对齐 Pi |
| 误差点区 | `误差点列窗`（空壳 `槽-P*`，仅与列头对齐；底图 `assets/c4-slot-empty.png`）+ 并列绝对层 `误差系列层` → 三系列（`传统基站` / `商用方案` / `DT辅助`），各含 `点列/点-Pi` + `连线（示意·非实现源）` | **数据契约按系列**：`errors[s][i]` → 系列 `点-Pi` + 同系列虚线；**禁止**从列槽读业务点。槽底图可 CSS/`img` 铺满槽；连线用 SVG `stroke-dasharray`，**禁止**照抄示意小矩形段 |
| 指标卡行 | 横排 flex 三卡固定宽：定位误差 ~975 / NLOS ~272 / 吞吐外壳 ~623；`gap:12` | flex 三卡；**以初始帧为 token 基准**，不要再按态抄另一套宽度 |
| 吞吐 | `吞吐卡外壳（非业务层）` 内嵌 `吞吐率对比卡` | DOM 一层即可，外壳不必复刻 |
| 地图浮层 | `layout:none` 四角钉住 | Overlay；勿进地图 transform |
| 轨迹图例 | 四条可编辑图例为正式源 | 忽略名为 `轨迹图例贴图（非实现源）` 的贴图层 |
| 误差悬停浮层 | 如 `P13定位误差浮层`，绝对坐标可能不贴槽 | 完成态按悬停槽 Pi 锚定；勿抄浮层 left/top |
| 底栏容器 | 仅初始帧有「底栏容器」包裹；底栏本身 vertical flex | 统一认「底栏」即可 |

## 动态图形契约

### 地图

- 坐标系：`code/web/src/cases/case3-v2/mapProjectionV2.ts`，底图 `site-2d.jpg`
- 层序：底图 < 预期绿虚 < 三实时 < 点位 < UE
- 收齐：三 realtime 同一行到齐才推进
- Pencil 折线仅为代表态

### 误差窗

- Y：米，示意 0–0.4；实现按本轮误差范围定轴，不要写死
- 三色：传统 `$c4-bs`、商用 `$c4-gaode`、DT `$c4-dt`

### CDF

- X 误差（m），Y 概率 0–1，单调
- 同概率误差越小越好；不强制曲线按方案名排序

## 数据绑定与内容边界

| 字段 | 空值 | 超长 |
|---|---|---|
| 状态文案 | 未开始 / 测试中 / 已完成 / 等待最终统计 | 一行截断 |
| 误差数字 | 空槽不写 0 | 示意 2 位；契约再定精度 |
| NLOS | `--` | 百分比；脚注「高不表示更好」 |

## 禁止实现

- 禁止暂停/继续、单方案显隐、3D、反射路径
- 禁止用 UX 的 20 点、NLOS 60、CEP Δ%、CDF 厘米轴做硬编码
- 禁止把 Pencil 示意数字写进运行代码
- 禁止把 Pencil 底栏/浮层绝对 `x`/`y` 当布局契约照抄
- 禁止把 `轨迹图例贴图（非实现源）` 或 `吞吐卡外壳（非业务层）` 当成第二套业务组件
- 禁止在 65535 / dt_type / 完成点数不足 / 吞吐收齐上自行定规则
